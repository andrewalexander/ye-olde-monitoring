How it works

Nothing logs this app's requests for it, so middleware.Wrap records each one and sends them in batches to POST /ingest with a bearer token (source=middleware, site=example). Use this pattern only for a site that's not behind Caddy. Behind Caddy, the access log already has every request (see examples/caddy-site).
