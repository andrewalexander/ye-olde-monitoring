How it works

This is how a real static site uses dnscount. It's just files: index.html, about.html and style.css, served by Caddy's file_server. There's no Go and nothing to run.

  • Caddy writes every request to its JSON access log, and dnscount ingest-access -follow turns each line into a hit. That log is the only record of a visit, and the fail2ban guard reads the same file.
  • The counter below is a plain <img src="/counter.svg?site=caddy-site">. Caddy proxies /counter.* to dnscount serve, which only reads: one visitor per IP per day that loaded a page. Reloading doesn't raise it, and nothing can be counted twice.
